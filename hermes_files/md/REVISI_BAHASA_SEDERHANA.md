### **2.2.2 Aplikasi Berbasis Web**

#### **BEFORE (Terlalu teknis):**
```
Aplikasi berbasis web adalah perangkat lunak yang dijalankan pada server dan diakses 
melalui browser web, tanpa memerlukan instalasi pada perangkat klien (Rosa & Shalahuddin, 
2018). Berbeda dengan aplikasi desktop tradisional yang harus diinstal di setiap perangkat 
pengguna, aplikasi web hanya memerlukan browser dan koneksi internet untuk diakses. Hal 
ini memudahkan distribusi pembaruan karena perubahan cukup dilakukan di server saja, 
tanpa perlu mengupdate setiap perangkat klien secara manual.

Aplikasi web juga memungkinkan akses simultan dari berbagai perangkat dan lokasi, sehingga 
cocok untuk sistem yang melayani banyak pengguna seperti dashboard pengelolaan aduan publik. 
Dalam konteks KMC, pendekatan web-based memungkinkan petugas dari berbagai OPD untuk 
memantau dan menangani aduan tanpa terikat pada satu perangkat atau lokasi kantor tertentu.
```

#### **AFTER (Lebih familiar):**
```
Aplikasi berbasis web adalah aplikasi yang dijalankan pada server dan diakses melalui 
browser web, tanpa memerlukan instalasi pada komputer pengguna (Rosa & Shalahuddin, 2018). 
Berbeda dengan aplikasi desktop yang harus diinstal di setiap komputer, aplikasi web hanya 
memerlukan browser dan koneksi internet untuk diakses. Hal ini memudahkan proses update 
karena perubahan cukup dilakukan di server saja, tanpa perlu mengupdate setiap komputer 
pengguna secara manual.

Aplikasi web juga memungkinkan akses bersamaan dari berbagai perangkat dan lokasi, sehingga 
cocok untuk sistem yang melayani banyak pengguna seperti dashboard pengelolaan aduan publik. 
Dalam konteks KMC, pendekatan berbasis web memungkinkan petugas dari berbagai OPD untuk 
memantau dan menangani aduan tanpa terikat pada satu perangkat atau lokasi kantor tertentu.
```

### **2.2.3 Manajemen Aduan**

#### **BEFORE:**
```
Manajemen aduan adalah proses sistematis untuk menerima, mencatat, mengklasifikasikan, 
menindaklanjuti, dan menyelesaikan keluhan atau laporan dari masyarakat (ISO 10002:2018). 
Sistem manajemen aduan yang efektif harus mampu menangani volume tinggi, memberikan 
transparansi kepada pelapor, serta memastikan akuntabilitas penanganan oleh instansi 
terkait. Standar ISO 10002:2018 menetapkan pedoman untuk merancang dan menerapkan proses 
penanganan keluhan yang efektif dan efisien, termasuk prinsip-prinsip seperti aksesibilitas, 
responsivitas, objektivitas, kerahasiaan, dan pendekatan berorientasi pelanggan.
```

#### **AFTER:**
```
Manajemen aduan adalah proses yang teratur untuk menerima, mencatat, mengelompokkan, 
menindaklanjuti, dan menyelesaikan keluhan atau laporan dari masyarakat (ISO 10002:2018). 
Sistem manajemen aduan yang efektif harus mampu menangani jumlah aduan yang besar, 
memberikan keterbukaan kepada pelapor, serta memastikan tanggung jawab penanganan oleh 
instansi terkait. Standar ISO 10002:2018 menetapkan pedoman untuk merancang dan menerapkan 
proses penanganan keluhan yang efektif dan efisien, termasuk prinsip-prinsip seperti 
kemudahan akses, kecepatan respon, sikap objektif, kerahasiaan, dan pendekatan yang 
berfokus pada pelanggan.
```

**Perubahan:**
- "proses sistematis" → "proses yang teratur" ✅
- "mengklasifikasikan" → "mengelompokkan" ✅
- "volume tinggi" → "jumlah aduan yang besar" ✅

### **2.2.5 Notifikasi Real-Time**

#### **BEFORE:**
```
Notifikasi real-time adalah mekanisme penyampaian informasi secara instan kepada pengguna 
pada saat terjadinya suatu kejadian atau perubahan status dalam sistem (Nugroho & Purnama, 
2020). Sistem notifikasi real-time memungkinkan pengguna untuk segera mengetahui informasi 
penting tanpa harus melakukan pemeriksaan manual secara berkala, sehingga meningkatkan 
responsivitas dalam pengambilan keputusan. Teknologi yang umum digunakan untuk notifikasi 
real-time meliputi WebSocket, Server-Sent Events (SSE), atau mekanisme polling pada 
interval pendek.
```

#### **AFTER:**
```
Notifikasi real-time adalah cara penyampaian informasi secara langsung kepada pengguna 
pada saat terjadinya suatu kejadian atau perubahan status dalam sistem (Nugroho & Purnama, 
2020). Sistem notifikasi real-time memungkinkan pengguna untuk segera mengetahui informasi 
penting tanpa harus melakukan pengecekan manual secara rutin, sehingga meningkatkan 
kecepatan respon dalam pengambilan keputusan. Teknologi yang umum digunakan untuk notifikasi 
real-time adalah teknologi notifikasi otomatis seperti WebSocket atau Server-Sent Events.
```

**Perubahan:**
- "mekanisme" → "cara" ✅
- "pemeriksaan manual secara berkala" → "pengecekan manual secara rutin" ✅
- "responsivitas" → "kecepatan respon" ✅
- "meliputi WebSocket, Server-Sent Events (SSE), atau mekanisme polling pada interval pendek" → "teknologi notifikasi otomatis seperti WebSocket atau Server-Sent Events" ✅ (lebih sederhana, hapus jargon teknis)
